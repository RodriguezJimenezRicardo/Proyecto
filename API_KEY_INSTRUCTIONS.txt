# API Key de TMDb
# Obtén tu API key gratis en: https://www.themoviedb.org/settings/api
#
# Pasos para obtener la API Key:
# 1. Ve a https://www.themoviedb.org/
# 2. Crea una cuenta o inicia sesión
# 3. Ve a Settings > API
# 4. Solicita una API Key (selecciona "Developer" y llena el formulario)
# 5. Copia tu API Key (v3 auth) y pégala en el archivo TMDbApiService.kt
#
# Reemplaza "TU_API_KEY_AQUI" con tu API key real en:
# app/src/main/java/com/example/proyecto/data/remote/TMDbApiService.kt
#
